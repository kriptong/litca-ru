# StiryVoice

Мужской голос для озвучки рассказов: русский язык, разговорный стиль. Утверждён по пробе `voice-04`.

Файлы:
- `sample.mp3` — образец голоса: начало рассказа «Заземление», записан без обработки.
- `voice.json` — параметры голоса, тексты проб и настройки обработки.
- `process_narration.py` — склейка частей и обработка: высота +0,5 полутона, темп ×1,07, паузы длиннее 0,4 с сокращаются до 0,3 с, громкость -16 LUFS.

Как озвучивать рассказ:
1. Голос привязан к сессии (`voice_id`). В новой сессии зарегистрируйте голос заново и сверьтесь с `sample.mp3`.
2. Озвучивайте текст частями не длиннее 1500 знаков, все части одним и тем же `voice_id`.
3. Сохраните части в WAV и склейте их одной командой:
   `python3 voices/StiryVoice/process_narration.py --out stories/audio/<имя>.mp3 --title "<Название>" часть1.wav часть2.wav ...`

Пример: «Заземление» — `stories/audio/zazemlenie.mp3`, 11:36. Файл не добавлен в Git из-за размера.

# litca-ru — локальная нейросеть на ноутбуке

Инструкция для Windows 10/11, 16 ГБ RAM, без отдельной видеокарты.
Всё работает **офлайн**: после установки интернет не нужен, запросы никуда не уходят.

---

## Что ставим и почему именно это

| Компонент | Что это | Зачем |
|---|---|---|
| **Ollama** | Программа, которая запускает нейросети на вашем компьютере | Ставится в один клик, не требует прав администратора, у неё есть обычное окно чата |
| **Gemma 4 E4B** (`gemma4:e4b`) | Нейросеть от Google, 4,5 млрд «активных» параметров, файл 6,6 ГБ | Заметно умнее моделей 2B-класса, при этом реально работает на процессоре |

**Почему Gemma 4 E4B, а не что-то крупнее.** На ноутбуке без видеокарты скорость
упирается в память: модель 9–12B на таком железе выдаёт 3–7 токенов в секунду,
то есть один абзац ответа печатается минуту. E4B на похожем ноутбуке
(i5-13420H, 16 ГБ, только процессор) показывает около **10 токенов в секунду** —
это уже можно использовать для писем, пересказов, редактирования и вопросов-ответов.

Честно о качестве: по формальным тестам (MMLU Pro 69,4%, мультиязычный MMMLU 76,6%)
E4B обходит даже Gemma 3 27B, и на русском он работает нормально — но
**независимых замеров именно русского языка для этой модели пока нет**, есть только
отзывы пользователей. Если после установки качество русского текста вас не устроит,
в разделе «Если что-то не так» есть варианты специально русскоязычных моделей.

Скорость (замеры на CPU, 16 ГБ RAM):

| Модель | Размер | Скорость | Комментарий |
|---|---|---|---|
| `gemma4:e2b` | 4,6 ГБ | ~21 ток/с | Быстро, но заметно проще. Хорошо для коротких ответов |
| **`gemma4:e4b`** | **6,6 ГБ** | **~10 ток/с** | **Основной выбор** |
| `gemma4:12b` | 8 ГБ | ~3–5 ток/с | Медленно, и русский у неё не лучше |
| `qwen3.5:9b` | 7 ГБ | ~5–7 ток/с | По отзывам, на русском не лучше E4B, но медленнее |

## Вариант 1. Автоматически (скрипт)

Скачайте папку с репозиторием (кнопка **Code → Download ZIP**, затем распакуйте)
или склонируйте её. В папке:

1. Двойной клик по **`install.cmd`**.
2. Дождитесь надписи «Установка завершена успешно». Скачивание займёт время:
   установщик ~1,9 ГБ, модель 6,6 ГБ.
3. Откройте **Ollama** из меню «Пуск» — это окно чата.

Что скрипт делает за вас: проверяет Windows и свободное место, ставит Ollama с
проверкой цифровой подписи, отключает облачные функции, ставит контекст 8192 токена,
скачивает модель, делает пробный запрос на русском и показывает скорость.

Полезные варианты запуска (в командной строке, из папки со скриптом):

| Команда | Что делает |
|---|---|
| `install.cmd -Lite` | Лёгкая модель `gemma4:e2b` — примерно вдвое быстрее |
| `install.cmd -Model "gemma4:12b"` | Другая модель |
| `install.cmd -ContextLength 16384` | Больше контекста (нужно больше RAM) |
| `install.cmd -SkipPull` | Не скачивать модель (уже есть или нет интернета) |
| `install.cmd -KeepCloud` | Не отключать облачные функции |

Если PowerShell ругается на политику запуска — запускайте именно `install.cmd`,
он обходит это сам. Скрипт ничего не удаляет и не меняет в системе, кроме
установки Ollama в профиль пользователя.

## Вариант 2. Вручную, три шага

1. **Поставьте Ollama.** Откройте <https://ollama.com/download> и запустите
   `OllamaSetup.exe`. Права администратора не нужны.
2. **Скачайте модель.** Откройте «Пуск → Ollama». В окне чата выберите модель
   `gemma4:e4b` — она скачается сама (6,6 ГБ, один раз). Либо в PowerShell:

   ```powershell
   ollama pull gemma4:e4b
   ```

3. **Отключите облако (по желанию, но для полной автономности стоит).**
   В приложении: **Settings → Cloud** → выключить. После этого доступны только
   локальные модели, без веб-поиска и обращений к ollama.com.

## Как пользоваться

- **Чат.** Открывается из меню «Пуск». Модель выбирается в списке сверху.
- **Кнопка Think (размышления).** По умолчанию выключена — и это правильно для
  ноутбука: с ней модель сначала долго «думает», и на процессоре это очень
  заметно. Включайте только для сложных задач (разбор документа, расчёты, код).
- **Context length** в настройках. Скрипт ставит 8192 токена — примерно 15–20
  страниц текста в одном диалоге. Больше не надо: контекст съедает оперативную
  память и замедляет ответы. Если нужен очень длинный документ, поднимите до
  16384, но следите, чтобы компьютер не начал тормозить.
- **Длинные диалоги.** Если модель начала повторяться или понесла околесицу —
  начните новый чат. Это нормально для небольших моделей.
- **Из командной строки:**

  ```powershell
  ollama run gemma4:e4b --think=false    # без «размышлений», быстрее
  ollama run gemma4:e4b                  # с размышлениями
  ollama ps                              # что сейчас загружено в память
  ollama list                            # какие модели скачаны
  ollama rm gemma4:e2b                   # удалить ненужную модель
  ```

- **Из своих программ.** Локальный API без интернета:
  `POST http://localhost:11434/api/chat`. В теле запроса можно передать
  `"think": false`, `"options": {"num_ctx": 8192}`.

## Офлайн

После того как модель один раз скачалась, интернет не нужен вообще: ни для чата,
ни для API. Модели лежат в `C:\Users\<вы>\.ollama\models`.

Два предостережения:

- Ollama по умолчанию **сама проверяет обновления**. Их можно отключить:
  **Settings → Auto-download updates** → выключить.
- Режим «без облака» не запрещает скачивание моделей — он лишь убирает облачные
  модели и веб-поиск. То есть в самолёте всё работает, а скачать новую модель
  можно только при интернете.

## Стоимость и лицензии

Всё, что ставит скрипт, — бесплатно, без регистрации и без ключей API.

| Компонент | Лицензия | Что это значит |
|---|---|---|
| Ollama | MIT | Бесплатно, в том числе для работы |
| Gemma 4 E4B | Apache 2.0 (файл лицензии входит в саму модель) | Бесплатно, включая коммерческое использование |
| T-lite 2.1 (опция) | Apache 2.0 | То же |
| GigaChat 3.1 Lightning GGUF (опция) | MIT | То же |

Ни подписки, ни пробного периода, ни аккаунта. Платите только за электричество:
час генерации на ноутбуке — примерно 0,04 кВт·ч.

Единственное платное в Ollama — облачные модели с тегом `:cloud` и облачный тариф
самого Ollama. К вашей локальной модели они отношения не имеют, работают через
интернет, и скрипт их отключает (`disable_ollama_cloud`), так что случайно попасть
на платное нельзя.

Осторожно: если какой-то сайт просит деньги или данные карты за «Ollama», «Gemma»
или «активацию модели» — это мошенники. Скачивать нужно только с ollama.com и
huggingface.co.

## Если что-то не так

**Медленно (меньше 5 токенов в секунду).**
Возьмите лёгкую модель: `install.cmd -Lite` или `ollama pull gemma4:e2b`.
Проверьте, что модель не ушла частично в оперативную память: `ollama ps`
показывает распределение CPU/GPU и размер контекста.

**Русский текст с ошибками или «кальками» с английского.**
Попробуйте по очереди, что больше понравится:

```powershell
ollama pull qwen3.5:9b     # медленнее, другой стиль
ollama pull gemma4:12b     # крупнее и умнее, но на CPU медленно
```

Отдельно существует русскоязычная **GigaChat 3.1 Lightning** от Сбера (10 млрд
параметров, но активны только 1,8 млрд, поэтому она быстрая). Она обучена на
русском с нуля и в отзывах хвалят её русский, но перевод с английского у неё
слабее. Запуск:

```powershell
ollama run hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M
```

Это **экспериментальный вариант**: в Ollama его почти никто не проверял
(официально он тестировался в LM Studio), поэтому если ответы будут странными —
дело в этом, а не в вашем компьютере.

**Модель не влезает в память / компьютер начинает тормозить.**
Уменьшите контекст до 4096 (Settings → Context length), закройте браузер
с десятками вкладок. 16 ГБ хватает E4B, но не хватает E4B и одновременно Chrome.

**Можно ли задействовать встроенную видеокарту?**
Технически да — Ollama умеет Intel/AMD через Vulkan, но встроенные GPU по
умолчанию отключены, потому что на них часто получается медленнее, чем на
процессоре. Если хочется попробовать: задайте переменную окружения
`OLLAMA_IGPU_ENABLE=1`, перезапустите Ollama и сравните `ollama ps` и скорость.
Не ждите чуда: на встроенной графике выигрыш бывает только у совсем маленьких моделей.

**Где смотреть ошибки.**
`%LOCALAPPDATA%\Ollama\server.log` и `app.log`. Настройки — в `%USERPROFILE%\.ollama`.

## Как всё удалить

1. «Параметры → Приложения → Установленные приложения → Ollama → Удалить».
2. Удалите папки `C:\Users\<вы>\.ollama` (модели, ~10 ГБ) и
   `C:\Users\<вы>\AppData\Local\Ollama` (настройки и логи).

## Русскоязычные модели: короткая справка

| Модель | Как запустить | Плюсы | Минусы |
|---|---|---|---|
| Gemma 4 E4B | `ollama run gemma4:e4b` | Умная, быстрая для своего размера, в официальном каталоге | Русский — «хороший», но не родной |
| Qwen 3.5 9B | `ollama run qwen3.5:9b` | Другой стиль письма, часто аккуратнее в формулировках | На CPU заметно медленнее |
| T-lite 2.1 (Т-Банк) | `ollama run t-tech/T-lite-it-2.1:q4_K_M` | Сделана на русском, лидер российских открытых бенчмарков (Ru Arena Hard 83,9) | 8B (файл 5,0 ГБ), на CPU медленнее E4B |
| GigaChat 3.1 Lightning | `ollama run hf.co/ai-sage/GigaChat3.1-10B-A1.8B-GGUF:Q4_K_M` | Родной русский, очень быстрая (активны 1,8 млрд параметров) | В Ollama почти не проверена, слабее переводит с английского |

Проверить любую из них просто: скачали, выбрали в списке моделей, поговорили.
Модели не конфликтуют, каждая занимает своё место на диске.

## Что проверено, а что нет

Проверено: документация и исходный код Ollama (установка, тихие флаги, файл
`server.json`, переменные окружения, поведение встроенных GPU), размеры моделей
по манифестам реестра Ollama, синтаксис `install.ps1`.

Не проверено: запуск скрипта на реальной Windows (здесь нет Windows),
скорость и качество моделей на вашем ноутбуке — цифры выше взяты из
независимых замеров на похожем железе. Если что-то пойдёт не так, пришлите
текст ошибки — поправим.
